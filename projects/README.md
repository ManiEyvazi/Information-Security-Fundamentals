## 📝 Краткое описание

- **🐉 Проект 1** — развёртывание Kali Linux в виртуальной машине VirtualBox с настройкой оборудования и ручной установкой системы.
- **🕸️ Проект 2** — установка и настройка уязвимого веб-приложения DVWA, инициализация базы данных, установка уровня безопасности Low.
- **🔑 Проект 3** — атака методом грубой силы на форму входа DVWA с помощью Hydra и словаря `rockyou.txt`.
- **🔍 Проект 4** — сканирование веб-сервера DVWA сканером Nikto и анализ проблем конфигурации (отсутствующие заголовки безопасности).
- **🕷️ Проект 5** — перехват и автоматизированный перебор учётных данных через Burp Suite Intruder с анализом длины ответа.
