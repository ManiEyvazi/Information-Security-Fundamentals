## 🔬 Краткое описание лабораторных работ

### Лабораторная работа № 1. Установка и конфигурация ОС на виртуальную машину

- **Цель:** Приобретение практических навыков установки ОС на виртуальную машину.
- **Инструменты:** VirtualBox, Rocky Linux.
- **Ключевые навыки:** Создание ВМ, настройка параметров, установка ОС, установка Guest Additions, анализ загрузки через `dmesg`.

---

### Лабораторная работа № 2. Дискреционное разграничение доступа

- **Цель:** Изучение атрибутов файлов и прав доступа в Linux.
- **Инструменты:** `chmod`, `ls -l`, `lsattr`, `id`, `groups`.
- **Ключевые навыки:** Создание пользователей, работа с правами `r`, `w`, `x`, заполнение таблиц прав доступа.

---

### Лабораторная работа № 3. Атрибуты файлов для групп пользователей

- **Цель:** Изучение прав доступа для групп пользователей.
- **Инструменты:** `gpasswd`, `newgrp`, `chmod g+rwx`.
- **Ключевые навыки:** Добавление пользователя в группу, проверка прав от имени другого пользователя.

---

### Лабораторная работа № 4. Расширенные атрибуты файлов

- **Цель:** Изучение расширенных атрибутов `a` (append only) и `i` (immutable).
- **Инструменты:** `chattr`, `lsattr`.
- **Ключевые навыки:** Установка и снятие атрибутов, анализ их влияния на операции с файлами.

---

### Лабораторная работа № 5. SetUID-, SetGID- и Sticky-биты

- **Цель:** Изучение механизмов смены идентификаторов и специальных битов.
- **Инструменты:** `gcc`, `chmod u+s`, `chmod g+s`, `chmod +t`.
- **Ключевые навыки:** Написание программ на C, работа с SetUID/SetGID, исследование Sticky-бита на `/tmp`.

---

### Лабораторная работа № 6. SELinux и веб-сервер Apache

- **Цель:** Практическое знакомство с SELinux.
- **Инструменты:** `getenforce`, `sestatus`, `seinfo`, `semanage`, `chcon`.
- **Ключевые навыки:** Работа с контекстами безопасности, настройка портов, анализ логов SELinux.

---

### Лабораторная работа № 7. Однократное гаммирование

- **Цель:** Освоение режима однократного гаммирования (One-Time Pad).
- **Инструменты:** Python 3.
- **Ключевые навыки:** Реализация шифрования/дешифрования XOR, восстановление ключа, подбор ключа для целевого сообщения.

---

### Лабораторная работа № 8. Шифрование двух текстов одним ключом

- **Цель:** Изучение уязвимости при повторном использовании ключа.
- **Инструменты:** Python 3.
- **Ключевые навыки:** Анализ `C1 ⊕ C2 = P1 ⊕ P2`, восстановление текстов без знания ключа.
