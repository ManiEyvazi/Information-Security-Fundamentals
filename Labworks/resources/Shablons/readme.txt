## 📚 About This Repository
This repository contains laboratory work and practical assignments completed for the "Operating System Administration Basics" course. The work demonstrates practical skills in system administration, configuration, and management of operating systems.

## 🎯 Course Overview
The course covers fundamental concepts of operating system administration including:
- System installation and configuration
- User and group management
- File system administration
- Network configuration and management
- Security fundamentals
- Service management and automation
