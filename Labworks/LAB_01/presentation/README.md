# Лабораторная работа №1: Unattended установка Windows

## 📚 Тема
Автоматизированная (необслуживаемая) установка операционной системы Windows с использованием файлов ответов.

## 🎯 Цель работы
Изучить принципы создания файлов автоматической установки Windows, освоить работу с Windows System Image Manager (WSIM) и научиться создавать загрузочные носители для unattended-установки.

## 📋 Теоретическая часть
- Что такое Unattended установка
- Преимущества автоматизации развертывания ОС
- Инструменты Windows ADK и Windows SIM
- Структура файла autounattend.xml
- Этапы установки: windowsPE, offlineServicing, specialize, oobeSystem

## 🛠 Практическая часть
1. Установка Windows ADK и Windows SIM
2. Создание файла autounattend.xml с настройками:
   - Язык и региональные стандарты
   - Разметка диска
   - Локальный администратор
   - Ключ продукта
3. Создание загрузочной флешки с файлом ответов
4. Тестирование автоматической установки

## 📁 Результаты работы
- Файл `autounattend.xml`
- Скриншоты процесса установки
- Отчет о проделанной работе

4. Как настроить разметку диска при автоматической установке?
